# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

```bash
python3 -m pytest -q
```

## 编译检查

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询；运行过程中不需要单独的数据库或网络服务。

## 请假更正的归属与一致性

`leave_correction` 事件可携带 `business_date`（业务日期，按培养方案时区解释）或 `checkin_event_id`（关联原签到，跨日签到按各日实际秒数占比分摊）来明确归属；重放时正向调整先入明细、负向调整随后扣减，单日扣到零为止，不足部分溢出到其他日期，仍不足的部分被丢弃并记入 `correction_overflow` 异常。缺少归属字段的历史更正按确定性兜底规则分配（负向从最早有量日期起扣、正向计入最近确认日），并记入 `unattributed_correction` 异常。任意快照中每个学生的每日明细均不为负，且各日合计恒等于总学时；异常列表随快照持久化，冻结与重启后仍可审计。
